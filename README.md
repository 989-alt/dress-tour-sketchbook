# 드레스 투어 스케치북

웨딩드레스 시착 후 기억을 디지털로 재구성하는 클라이언트 사이드 웹앱.
슬라이더·드롭다운으로 11개 디자인 파라미터(실루엣·넥라인·소매·보디스·등판·스커트·원단·장식·컬러·베일·액세서리)를 조합해 드레스를 SVG로 렌더링하며, 신부 사진 위에 합성·비교할 수 있습니다. 모든 데이터는 브라우저(IndexedDB)에만 저장됩니다.

## 개발

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 빌드
npm test         # Vitest 단위 테스트
```
